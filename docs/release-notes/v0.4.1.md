# v0.4.1

v0.4.0's tag exists. Its **image does not**: the release workflow's Windows
gate runs `choco install make`, the community feed's search index 404'd that
package, GoReleaser and GHCR were skipped. `go install …@v0.4.0` still
resolves; `ghcr.io/calvinchengx/arm-emulator:0.4.0` was never pushed.

This tag is that same tree plus a fallback: if Chocolatey search misses
`make`, the nupkg is fetched by version and installed from disk. Pull **0.4.1**.

Nothing on the ARM surface changed from v0.4.0.
